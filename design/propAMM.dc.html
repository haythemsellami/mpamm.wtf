MATCH — nothing moved the venue before the fill's tx index and the quoter's number equals the realised amount. INTERVENED — something did move it first (another fill, or the keeper repricing), so a block-boundary replay would read as a false divergence; the prestate replay still matched. SENDER-VARIANCE — same block, same amount, different from: unset / zero / random EOA / FastLane / solver. A quoter that flatters a simulation would fail here. NOT TESTABLE — the check could not be run at all, so no verdict of any kind is implied. ThogAMM's fill decoder matches none of the contract's current logs, which is an indexer defect on our side, not a finding about the venue.
